# How Would You Build a City 
1 lập trình viên không thể quản lý đc hết. Giống như thành phố hoạt động. Chúng hoạt động vì các thành phố có các nhóm người quản lý các khu vực cụ thể của thành phố, hệ thống nước, hệ thống điện, giao thông, thực thi pháp luật, quy tắc xây dựng, v.v.
