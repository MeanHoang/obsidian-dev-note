# News Summary — 2026-05-21

## 🔥 Top 3 đáng đọc nhất
1. **[Shopify: Variant Publishable + Agentic Storefronts admin page + market-scoped discounts (May 2026)](https://shopify.dev/changelog)** — Trio update đáng chú ý nhất tháng cho merchant: từ giờ có thể publish/unpublish từng **variant** theo channel (trước chỉ làm được ở mức product), discount giới hạn theo **market / region / sales channel / B2B vs retail / online vs POS**, và **Agentic Storefronts** có riêng 1 trang trong admin (Sales channels → Agentic) hiển thị query nào trỏ tới product trong ChatGPT/Copilot + doanh thu attribute từ AI channel. Joy Loyalty cần kiểm tra: discount API v2026-07 đã có field market scope chưa, reward variant có nên gating theo channel không.
2. **[Claude Code Week 20 (11–15/05): `claude agents` view, `/goal`, fast mode Opus 4.7 default, Rewind "Summarize up to here"](https://code.claude.com/docs/en/whats-new)** — User dùng Claude Code daily nên đáng nắm: lệnh `claude agents` mở 1 màn hình thấy mọi session đang chạy/blocked/done (kể cả `claude --bg`), `/goal` giữ Claude làm việc xuyên turn đến khi điều kiện hoàn thành đạt, fast mode giờ chạy Opus 4.7 mặc định, và menu Rewind có nút "Summarize up to here" nén context cũ trong cùng session.
3. **[Shopify: Expiring offline access tokens bắt buộc cho mọi public app từ 1/1/2027](https://shopify.dev/changelog/expiring-offline-access-tokens-required-for-all-public-apps-as-of-january-1-2027)** — Từ ngày 1/1/2027 mọi public app (incl. Joy Loyalty) phải migrate sang **expiring offline access token** thay vì non-expiring để gọi Admin API. Đây là breaking change về auth flow — cần plan refresh token rotation, update OAuth flow, test merchant impact trước cuối Q4/2026.

## 🛒 Shopify Platform & API
- ⭐ **[Variant is now Publishable — fine-grained channel visibility](https://shopify.dev/changelog)** ([Shopify Updates May 2026](https://www.fudge.ai/blog/shopify-updates-may-2026/))
  **Đây là gì:** trước đây Shopify chỉ cho publish/unpublish ở mức `Product` per sales channel; nay từng `ProductVariant` cũng có flag publishable riêng. API 2026-07 đã expose.
  **Vì sao đáng đọc:** Joy Loyalty có thể tạo "exclusive reward variant" chỉ hiển thị trên Online Store cho VIP tier, không leak ra POS/agentic — UX gating sạch hơn nhiều so workaround tag/metafield hiện tại.
- ⭐ **[Agentic Storefronts dedicated admin page (Sales channels > Agentic)](https://www.fudge.ai/blog/shopify-updates-may-2026/)**
  **Đây là gì:** trang admin mới list query nào trong ChatGPT/Copilot trỏ về product của merchant, attribute doanh thu từ AI channel; trước đó chỉ là toggle ẩn trong settings.
  **Vì sao đáng đọc:** AI traffic giờ là 1 channel chính thức như Google/Meta — Joy nên đo loyalty member nào đến từ agentic source để tune offer.
- **[Market-scoped discounts — limit by market/region/channel/B2B/POS](https://www.fudge.ai/blog/shopify-updates-may-2026/)**
  **Đây là gì:** discount object giờ có scope theo market, region, sales channel, retail vs B2B, online vs POS.
  **Vì sao đáng đọc:** loyalty discount của Joy có thể chính xác hơn (vd "10% off chỉ cho US online, không POS") — giảm số discount Function custom.
- **[Customer accounts feature preview — single-column layout + UI extension navigation update (20/05)](https://shopify.dev/changelog/feature-preview-customer-account-improvements)**
  **Đây là gì:** customer account page được redesign 1-cột, navigation mới cho UI extension test thử.
  **Vì sao đáng đọc:** Joy widget loyalty trong customer account cần regression test với layout mới — bật feature preview trên dev store xem extension còn render đúng không.
- **[Shop Minis March–April 2026 update — optional consent hooks, intent launches, async storage limits (20/05)](https://shopify.dev/changelog/shop-minis-march-april-2026-update)**
  **Đây là gì:** Shop Mini = mini-app chạy trong Shop app; update mới: hook xin consent optional, intent để trigger contextual launch, giới hạn async storage, **deprecate localStorage/sessionStorage**.
  **Vì sao đáng đọc:** nếu Joy có Shop Mini extension (hoặc kế hoạch build) cần migrate khỏi localStorage trước EOL.
- **[Metaobject PRIVATE / PUBLIC_READ enum bị xoá ở API 2026-07 (20/05)](https://shopify.dev/changelog/removing-deprecated-private-and-publicread-enums-on-metaobject-definitions)**
  **Đây là gì:** 2 enum cũ trên `MetaobjectAdminAccess` bị xoá, dùng enum mới `MERCHANT_READ` / `PUBLIC_READ_WRITE` ...
  **Vì sao đáng đọc:** code Joy đang dùng metaobject (loyalty config?) cần audit query/mutation trước upgrade version 2026-07.
