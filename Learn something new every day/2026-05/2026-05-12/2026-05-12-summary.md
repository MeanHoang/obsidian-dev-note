## 🌐 Web Development
- **[Chrome 148: CSS name-only container queries + lazy loading cho `<video>`/`<audio>`](https://developer.chrome.com/release-notes/148)**
  **Đây là gì:** Container queries trước đây phải khai báo cả `container-type: inline-size` mới match được — Chrome 148 cho phép match by `container-name` only, đơn giản hóa CSS. Đồng thời `<video>` và `<audio>` hỗ trợ `loading="lazy"` giống `<img>`/`<iframe>` — defer load đến khi sắp visible.
  **Vì sao đáng đọc:** Landing page có hero video/podcast embed → set `loading="lazy"` tiết kiệm bandwidth + cải thiện LCP. Container queries name-only giúp viết responsive component không cần wrapper rườm rà.
- **[Chrome 148: Web Authentication Immediate UI mode](https://developer.chrome.com/release-notes/148)**
  **Đây là gì:** Mode mới của WebAuthn cho phép browser tự show passkey picker ngay khi page load (không cần user gesture) nếu credential khả dụng. Trước đây phải click button mới trigger được prompt.
  **Vì sao đáng đọc:** Flow login mượt hơn — landing page có thể auto-prompt passkey khi user đã đăng ký, giảm friction. Hữu ích cho merchant admin portal của Joy nếu chuyển sang passkey-first auth.

## 🛒 Shopify Platform & API
- ⭐ **[App deployment trong CI/CD cho mọi app qua App Automation Tokens](https://shopify.dev/changelog/app-deployment-in-cicd-is-now-available-for-all-apps)**
  **Đây là gì:** Token mới `SHOPIFY_APP_AUTOMATION_TOKEN` (tạo trên Dev Dashboard) thay thế `SHOPIFY_CLI_PARTNERS_TOKEN` (Partner Dashboard). Token scope theo từng app cụ thể — không thể dùng để deploy app khác trong cùng org, có expiration phải rotate.
  **Vì sao đáng đọc:** Bảo mật tốt hơn cho pipeline CI/CD Joy — nếu token leak, blast radius gói trong 1 app thay vì cả org. Migration cần update GitHub Actions workflow + rotate token định kỳ.
- **[Shopify thêm `actor` field cho subscription contract + billing attempt mutations](https://shopify.dev/changelog/add-actor-field-to-subscription-contract-and-billing-attempt-mutations)**
  **Đây là gì:** Mutation subscription giờ track ai thực hiện hành động — `CUSTOMER`, `MERCHANT`, hoặc `APP` (automated từ partner app). Trước đây không phân biệt được nguồn gốc thay đổi subscription.
  **Vì sao đáng đọc:** Joy build subscription-tier loyalty (Gold/Platinum recurring) → log actor giúp audit chính xác ai pause/cancel: customer tự làm, merchant từ admin, hay automation rule.
- **[Stricter rate limit cho bots/agents truy cập Storefront API + online store](https://shopify.dev/changelog/bots-and-agents-should-identify-themselves-via-web-bot-auth)** _(đã note tuần trước, có update mới)_
  **Đây là gì:** Shopify mở rộng enforcement — bot không identify qua Web Bot Auth header (signed HTTP message) sẽ bị throttle nặng hoặc block.
  **Vì sao đáng đọc:** Joy có background job poll Storefront API (sync inventory cho reward) → phải implement Web Bot Auth signature để tránh bị limit. Spec dựa trên IETF draft `http-message-signatures`.
