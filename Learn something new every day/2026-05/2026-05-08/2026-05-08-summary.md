## 🔒 Security
- ⭐ **[CVE-2026-42033 — Axios prototype pollution gadget (Snyk advisory, published 26/04)](https://security.snyk.io/vuln/SNYK-JS-AXIOS-16299904)**
  **Đây là gì:** Critical (CVSS 9.1) trong axios. Cơ chế: cần một prototype pollution có sẵn ở co-dependency → khi đó `Object.prototype.parseReviver` bị set → axios `transformResponse` gọi `JSON.parse(data, this.parseReviver)` sẽ dùng reviver của attacker → intercept/modify mọi JSON response, hoặc hijack transport. Fix: `npm i axios@1.15.1` (hoặc `0.31.1` cho legacy 0.x).
  **Vì sao đáng đọc:** Joy gần chắc chắn dùng axios trong Cloud Functions hoặc internal tool. Run `npm ls axios` cho mọi service, upgrade. Đây là minor patch, **không** breaking. Lesson tổng quát: code đọc property cấu hình từ object **bắt buộc** check `hasOwnProperty` hoặc `Object.create(null)` — đặc biệt khi có user-supplied config.
