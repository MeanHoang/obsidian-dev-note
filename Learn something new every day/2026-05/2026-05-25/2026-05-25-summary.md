## 🌐 Web Development
- **[Chrome 149 beta — CSS Gap Decorations, programmatic scroll Promises, WebSocket BFCache (06/05)](https://developer.chrome.com/blog/chrome-149-beta)**
  **Đây là gì:** Chrome 149 beta mở loạt feature: **CSS Gap Decorations** — style trực tiếp gap của grid/flex (border, color thay vì hack pseudo-element); **scroll Promise** — `element.scrollTo(...)` return Promise, await được khi smooth scroll xong hoặc bị huỷ; **WebSocket BFCache** — trang có WS mở vẫn vào back/forward cache (trước đây bị chặn, gây reload nặng).
