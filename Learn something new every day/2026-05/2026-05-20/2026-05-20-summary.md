## 🛠️ Coding Practice / Dev Craft
- **[TanStack supply chain postmortem — bài học `pull_request_target` + GitHub Actions cache + OIDC token](https://tanstack.com/blog/npm-supply-chain-compromise-postmortem)**
  **Đây là gì:** Postmortem chi tiết của TanStack team (11/05, update 15/05): attacker chain 3 lỗi — (1) workflow `bundle-size.yml` dùng `pull_request_target` chạy code từ fork untrusted; (2) cache poisoning xuyên trust boundary fork↔base; (3) trích OIDC token từ memory runner để publish trực tiếp lên npm. Phát hiện trong 20-26 phút bởi researcher độc lập.
  **Vì sao đáng đọc:** Bất kỳ project nào (Joy Loyalty included) dùng `pull_request_target` để chạy job lên PR từ fork là vector chính — audit lại workflow CI, không bao giờ chạy code untrusted với secret token; nếu cần token, dùng `pull_request` event hoặc require manual approval.

## 🔒 Security
- ⭐ **[CVE-2026-45321 TanStack + Mini Shai-Hulud worm — 170+ npm/PyPI package compromised, hơn 518M downloads ảnh hưởng](https://thehackernews.com/2026/05/mini-shai-hulud-worm-compromises.html)**
  **Đây là gì:** Campaign TeamPCP từ 11-14/05: malware npm self-propagate, đánh cắp credential (AWS/GCP/GitHub/SSH/crypto wallet), có cả "dead man's switch" wipe máy nếu dev revoke token. Đặc biệt: dùng OIDC token đánh cắp để **ký SLSA provenance hợp lệ** — package độc nhưng provenance check pass. Bao gồm TanStack (CVE-2026-45321 CVSS 9.6, react-router 12M/tuần), Mistral AI, Guardrails AI, OpenSearch, node-ipc (10M/tuần).
  **Vì sao đáng đọc:** **Action ngay cho Joy:** (1) audit `package-lock.json` xem có version `@tanstack/*` publish 11/05 19:20-19:26 UTC hoặc bất kỳ version `node-ipc` mới push 14/05; (2) rotate AWS/GCP/Firebase service account key + GitHub token nếu CI có pull npm gần đây; (3) lock CI pipeline về registry mirror hoặc dùng `npm ci --frozen-lockfile` + dependency pinning + verify provenance không còn đủ — phải audit hash.
