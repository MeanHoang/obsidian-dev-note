## 🔥 Top 3 đáng đọc nhất
1. **[Shopify admin intents — 7 Settings intents mới (06/05)](https://shopify.dev/changelog/more-admin-intents-now-support-settings)** — Đây là gì: admin intents là API cho phép app embedded mở thẳng một editor cụ thể trong Shopify Admin (vd "mở Settings → Notifications → Sender email") thay vì merchant phải tự click navigation. Bản update 06/05 thêm **7 intent mới** thuộc 4 nhóm: **Notifications** (sender email + staff notification), **Payments/Gift cards** (capture method + gift card expiration), **Delivery** (create + edit delivery profile), **Business** (business details). Mở dạng contextual overlay, không rời app. Joy có flow setup → tận dụng intent này gửi merchant trực tiếp đến field cần edit, giảm 2-3 click + tránh sai chỗ.
2. **[Firebase ra mắt Dart support cho Cloud Functions (experimental, 06/05)](https://firebase.blog/posts/2026/05/dart-functions-exp)** — Đây là gì: Cloud Functions for Firebase giờ chạy được code Dart cho **HTTPS + callable function** (preview, cần CLI flag để bật). Đi kèm **Dart Admin SDK experimental** truy cập Firestore + service Firebase. Author quảng bá lợi ích cho dev Flutter: cùng ngôn ngữ + tooling + data model client-server, AOT compile giảm cold-start so JIT. Joy không dùng Flutter → tin này không impact ngay, nhưng pattern đáng note: Firebase đang mở Cloud Functions ra ngoài Node/Python, có thể tương lai có Go/Rust. Theo dõi nếu cần optimize cold-start nặng.
3. **[BigQuery: bắt buộc MFA cho Google Ads transfer từ HÔM NAY 07/05](https://docs.cloud.google.com/bigquery/docs/release-notes)** — Đây là gì: BigQuery Data Transfer Service là tính năng schedule pull dữ liệu định kỳ từ Google Ads / YouTube / Merchant Center vào BigQuery. Từ 07/05/2026, **mọi transfer config mới** dùng individual user authentication (không phải service account) sẽ **bắt buộc MFA**. Config cũ vẫn chạy nhưng tạo mới sẽ bị block nếu user không bật MFA. Action: nếu Joy có pipeline analytics pull Google Ads vào BigQuery, kiểm tra account dùng auth cá nhân hay SA — nếu cá nhân, bật MFA trước khi tạo transfer mới.

## 🏗️ System Design / Architecture
- ⭐ **[Netflix: State of Routing in Model Serving — Switchboard → Lightbulb (May 2026)](https://netflixtechblog.com/state-of-routing-in-model-serving-16e22fe18741)**
  **Đây là gì:** bài đầu series multi-part về ML model serving infrastructure ở Netflix. Tổng quan **API abstraction trung lập domain** + traffic routing platform mà nhiều microservice domain-specific cùng dùng. Implement đầu tiên qua **Switchboard** (centralized routing), gặp scale-pain rồi evolve thành **Lightbulb** architecture. Scale: hundreds of model types, **1M req/s**. Bài định nghĩa lại "model" ở Netflix = **self-contained workflow** (pre-process + feature compute + ML predict + post-process) chứ không chỉ `infer(features) -> score`.
  **Vì sao đáng đọc:** Joy có thể không serve ML 1M req/s, nhưng pattern "centralized router + domain abstraction" áp dụng cho mọi service multi-tenant (vd dispatch event loyalty → 50 loại rule engine khác nhau). Cách đóng gói "self-contained workflow" còn dùng được cho discount Functions / event handler.

## 🌐 Web Development
- **[New to the web platform in March 2026 — name-only `@container` queries ship Firefox 149 + Safari 26.4](https://web.dev/blog/web-platform-03-2026)**
  **Đây là gì:** roundup chính thức từ web.dev. Tin nổi bật: **name-only `@container` queries** (declare container query chỉ bằng name, không bắt buộc size condition) đã có ở Firefox 149 + Safari 26.4 — giải pháp cho "naming wars" khi nhiều container lồng nhau. Còn có **scroll-triggered animations** (Chrome 146), `trigger-scope` property (Chrome 146 — giới hạn visibility của animation trigger name), `display: grid-lanes` cho masonry layout (Safari 26.4), `min()`/`max()`/`clamp()` trong `sizes` của `<img>` (Safari 26.4), `Iterator.concat(...)` (Chrome 146 + Safari 26.4), CloseWatcher API (Firefox 149).
  **Vì sao đáng đọc:** Polaris + Customer Account UI extension chạy trên engine modern → name-only container query bỏ được hack `container-type: inline-size` chỉ để gắn name. `Iterator.concat` thay được nhiều `[...a, ...b]` khi xử lý stream data (line item, log).
