## 🌐 Web Development

  **Đây là gì:** Monthly digest chính chủ Chrome team — feature web platform mới landing trong stable. Tháng này: **Chrome 147** + **Firefox 150** ra stable, không có Safari release.
  **Highlights:**
    - **`contrast-color()` CSS function** — Baseline (Chrome 147): hàm trả về black/white theo contrast cao nhất so background → tự động đảm bảo WCAG, không phải hard-code màu chữ.
    - **`animation-range-start/end` (Firefox 150)** — control vùng animation trong scroll-driven timeline.

  **Vì sao đáng đọc:** UI Joy embed trong Polaris có thể bỏ polyfill cho contrast tính toán + tận dụng view transition cho merchant dashboard. Scan 1 lần biết ngay feature nào đã safe.

  **Đây là gì thêm:** `--isolate` chạy mỗi test file trong global env mới (drain microtask, close socket, kill subprocess) nhưng cùng process — VM-level transpilation cache nên dependency chia sẻ chỉ parse 1 lần. `--shard=M/N` deterministic split theo path. zlib-ng cho gzip nhanh 5.5×.
  **Vì sao đáng đọc:** Test suite flaky vì global state leak là pain point phổ biến — `--isolate` fix ở root cause. Nếu CI Joy đang Jest và bottleneck ở test time, thử migrate sang Bun test runner đáng cân nhắc.

## 🛒 Shopify Platform & API
- ⭐ **[Idempotency mandatory cho inventory + refund mutations (2026-04)](https://shopify.dev/changelog/making-idempotency-mandatory-for-inventory-adjustments-and-refund-mutations)** (xem chi tiết Top 3)
  **Đây là gì thêm:** **Idempotency** = retry cùng request với cùng key không tạo side-effect lặp. Shopify từ trước đã có `@idempotent` directive optional cho `inventoryAdjustQuantities`, `refundCreate`, etc. Từ API 2026-04, **bắt buộc** — gọi không kèm directive sẽ throw runtime error.
  **Vì sao đáng đọc:** Joy có chỗ nào tự refund / điều chỉnh inventory? Webhook retry của Shopify mặc định at-least-once → không idempotent = double refund khi network blip. Pattern: generate UUID per business event (vd `joy-refund-${rewardId}-${attempt}`) làm idempotency key.
- **[Automatic CSS subsetting for `{% stylesheet %}` tags](https://shopify.dev/changelog/automatic-css-subsetting-for-stylesheet-tags)** (rollout 20/04/2026)
  **Đây là gì:** Trước đây Liquid theme serve toàn bộ CSS từ mọi `{% stylesheet %}` trên mỗi page load. Từ 20/04, Shopify chỉ deliver CSS thuộc section/block/snippet đang render trên page đó.
  **Vì sao đáng đọc:** Performance win miễn phí cho theme. **Pitfall:** nếu file A định nghĩa CSS class mà file B dùng (cross-file selector) → style thiếu trên page chỉ render B. Audit theme app extension Joy: mọi `{% stylesheet %}` chỉ style HTML trong cùng file hoặc render trực tiếp qua `{% render %}`.

## 🔒 Security
- ⭐ **[Vercel April 2026 security incident bulletin](https://vercel.com/kb/bulletin/vercel-april-2026-security-incident)** (xem chi tiết Top 3)
  **Đây là gì thêm:** **Supply chain attack pattern**: tool bên thứ ba (Context.ai — AI productivity tool) bị Lumma Stealer ~02/2026 → attacker chiếm OAuth token Google Workspace của nhân viên Vercel → pivot qua nhiều account để decrypt env var không-sensitive. Vercel khẳng định env var đánh dấu "sensitive" (encrypted, không decrypt được trên platform) **không bị đọc**. GitHub/npm/Microsoft đã verify không có npm package nào compromise.
  **Vì sao đáng đọc:**
    - **Lesson 1 — env var hierarchy:** mọi secret thật phải mark "sensitive" (Vercel) hoặc Secret Manager (GCP) — không bao giờ để plaintext env var.
    - **Lesson 2 — third-party AI tool risk:** review Granular OAuth scope cho mọi AI productivity tool (Context.ai, Linear AI, Notion AI…) connect Workspace.
    - **Lesson 3:** rotation runbook phải có sẵn — biết chính xác phải rotate cái gì khi 1 vendor breach.
