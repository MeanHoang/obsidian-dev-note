# News Summary — 2026-04-29

## 🔥 Top 3 đáng đọc nhất
1. **[Hydrogen April 2026 release (v2026.4.0)](https://hydrogen.shopify.dev/update/april-2026-release)** — Hydrogen là framework headless storefront của Shopify chạy trên React Router + Oxygen. Release 09/04: **Storefront API proxy giờ luôn bật** (bỏ option `proxyStandardRoutes`), **consent tracking chuyển server-side** qua cookie do proxy quản (deprecate cookie `_tracking_consent` cũ), thêm hỗ trợ Vite 7 + Vite 8, API bump lên 2026-04 (giới hạn 128KB cho JSON metafield, mã lỗi cart mới `MERCHANDISE_LINE_TRANSFORMERS_RUN_ERROR`). Nếu Joy có custom Hydrogen storefront → chạy `npx shopify hydrogen upgrade` và rà code gọi `createRequestHandler({ proxyStandardRoutes })`.
2. **[What's new for Cloud Run at Next '26](https://cloud.google.com/blog/products/serverless/whats-new-for-cloud-run-at-next26)** — Bài tổng hợp 23/04 từ Cloud Run team: **Cloud Run remote MCP server GA** (AI agent deploy app trực tiếp), **IAP gắn thẳng vào Cloud Run service GA** (không cần dựng load balancer riêng để gate auth), Go 1.26 GA, NVIDIA RTX PRO 6000 Blackwell GPU GA. Preview: SSH vào container, ephemeral disk, Cloud Run instances cho long-running agent. Joy có thể bỏ LB phía trước Cloud Run admin service và bật IAP rẻ hơn nhiều.
3. **[Bitwarden Statement on Checkmarx Supply Chain Incident](https://community.bitwarden.com/t/bitwarden-statement-on-checkmarx-supply-chain-incident/96127)** — Ngày 22/04 từ ~17:22-19:30 ET, package `@bitwarden/cli@2026.4.0` trên npm bị bản malicious thay thế (qua compromise pipeline build từ Checkmarx); 334 user lỡ tải về trước khi mitigation 93 phút sau. Action items chuẩn cho mọi npm consumer: lock version chặt, SBOM monitoring, rotate token nếu nghi nhiễm, dùng patch `2026.4.1`. Mỗi tháng giờ đã có 1-2 npm supply chain attack lớn → đừng coi `npm install` là an toàn mặc định.

Release notes tháng 4 chốt loạt feature: **Identity-Aware Proxy gắn thẳng vào service GA** (auth Google trước endpoint không cần load balancer), **deploy functions vào Cloud Run GA** (kết hợp DX của Functions với scaling của Run), Go 1.26 + PHP 8.5 GA, Ruby 4.0 Preview, source deploy hỗ trợ Ubuntu 24 LTS base image, **Cloud Run remote MCP server GA**.
  **Vì sao đáng đọc:** Joy có service backend trên Cloud Run → bật IAP cho admin/internal endpoint giờ chỉ cần config trên service, tiết kiệm chi phí LB và đơn giản hoá auth flow.
- **[Ship production AI features faster with Firebase AI Logic](https://firebase.blog/posts/2026/04/cloud-next-2026-ai-logic)**
  **Đây là gì:** Firebase AI Logic là layer SDK + backend giúp gọi Gemini/Imagen từ client app an toàn (App Check, secret management, rate limiting). Bài 22/04 công bố: **server prompt template hỗ trợ multi-turn chat + function calling** (system prompt + tool def nằm hẳn server-side, không lộ trong client binary), **App Check token chuyển single-use từ tháng 5/2026** chống replay, type-safe automatic function calling tự suy schema từ data class, explicit context caching theo cache ID giảm token cost, **hybrid on-device inference Android (PREFER_ON_DEVICE)** chạy Gemini Nano local khi máy hỗ trợ rồi fallback cloud.
  **Vì sao đáng đọc:** Nếu Joy có flow gọi LLM từ Shopify embedded app, mô hình "prompt template server-side + App Check" là pattern chuẩn để tránh user trích xuất prompt và lạm dụng API key.

## 🛒 Shopify Platform & API
- ⭐ **[Hydrogen April 2026 release](https://shopify.dev/changelog/hydrogen-april-2026-release)** (chi tiết ở Top 3)
- **[Shopify Scripts can no longer be edited or published starting April 15, 2026](https://changelog.shopify.com/posts/shopify-scripts-can-no-longer-be-edited-or-published)**
  **Đây là gì:** Shopify Scripts là feature Ruby script chạy ở checkout (line-item, shipping, payment). Từ **15/04/2026** không edit/publish được nữa, **30/06/2026 ngừng execute hoàn toàn**. Replacement là Shopify Functions (WebAssembly).
  **Vì sao đáng đọc:** Joy không dùng Scripts nhưng nếu merchant của Joy dùng app khác có Scripts thì checkout flow sẽ revert về default sau 30/06 → có thể ảnh hưởng promo/discount stack. Hữu ích để cảnh báo merchant.
- **[Automated testing for Shopify UI extensions with @shopify/ui-extensions-tester](https://shopify.dev/changelog/automated-testing-for-shopify-ui-extensions-with-shopify-ui-extensions-tester)**
  **Đây là gì:** Library official từ Shopify cho phép viết unit test UI extension (Checkout, Admin, Customer Account, POS) **không cần chạy Shopify host thật** — render extension trong DOM bình thường, mock typed `shopify` global, simulate user interaction.
  **Vì sao đáng đọc:** Joy build UI extension cho Admin/Customer Account → trước đây chỉ test được qua dev preview, giờ có thể viết Jest/Vitest test chạy trong CI, fast feedback. Đáng thử ngay tuần này.
