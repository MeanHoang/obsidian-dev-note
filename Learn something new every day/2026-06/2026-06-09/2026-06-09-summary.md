## 🔒 Security
- **[CVE-2026-40931 — bypass patch thư viện `compressing` (Node.js)](https://cyberpress.org/cve-2026-24884-patch/)** ([cyberpress.org](https://cyberpress.org/cve-2026-24884-patch/)) — *(3/6/2026)*
  **Đây là gì:** Patch gốc của CVE-2026-24884 dùng `path.resolve()` — chỉ xử lý chuỗi, không kiểm tra filesystem thật. Nếu một segment đường dẫn bí mật là symlink, check chuỗi vẫn pass nhưng kernel đi theo symlink khi ghi → ghi file tùy ý (vd đè `/etc/passwd`). Attack vector: pre-plant symlink trong repo, dev `git clone` rồi giải nén tarball có filename trùng. Fix v2.1.1 / v1.10.5 dùng `fs.lstatSync()` kiểm tra đệ quy từng segment.
  **Vì sao đáng đọc:** Bài học chung: **validate đường dẫn bằng chuỗi là không đủ** khi có symlink — áp dụng cho mọi code xử lý upload/giải nén file ở backend Joy (Cloud Run/Functions). Grep dependency tree xem có `compressing` không và bump version.
