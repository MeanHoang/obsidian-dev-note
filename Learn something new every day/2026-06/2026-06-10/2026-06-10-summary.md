## 🔥 Top 3 đáng đọc nhất
1. **[Cloud Run tại Next '26: đặt trần chi phí hàng tháng + MCP server GA](https://cloud.google.com/blog/products/serverless/whats-new-for-cloud-run-at-next26)** — Google cho phép set **maximum monthly spend** cho Cloud Run (service bị tắt khi chạm ngưỡng), thêm "Cloud Run instances" làm primitive mới và official remote MCP server đã GA. Joy nếu đọc lịch sử giao dịch gift card/store credit phải cập nhật logic phân loại trước 2026-07.
3. **[Universal Commerce Protocol (UCP) — chuẩn mở cho AI agent giao dịch](https://shopify.engineering/ucp)** — Shopify đồng phát triển với Google một giao thức mở để AI agent kết nối & mua hàng từ bất kỳ merchant nào. Định hình "agentic commerce" — hướng đi sẽ ảnh hưởng cách app loyalty tương tác với checkout do agent điều khiển.
