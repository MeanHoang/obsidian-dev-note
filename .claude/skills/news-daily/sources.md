# Search queries + preferred sources

## Query pattern theo topic

### System Design / Architecture
- `"system design case study [year]"`, `"engineering blog [company]"`
- `"distributed system architecture [year]"`, `"event-driven architecture"`
- `"scaling [technology] case study"`, `"microservice pattern [year]"`
- `site:shopify.engineering`, `site:netflixtechblog.com`, `site:stripe.com/blog/engineering`
- `site:highscalability.com`, `site:infoq.com/architecture`

### Firebase & GCP (user dùng hàng ngày)
- `"Firestore best practice [year]"`, `"Firestore data modeling [year]"`
- `"Cloud Run deploy pattern [year]"`, `"Cloud Functions v2 [year]"`
- `"Pub/Sub best practice"`, `"BigQuery cost optimization"`
- `"Firebase security rules pattern"`, `"Firebase Auth best practice [year]"`
- `site:firebase.blog`, `site:cloud.google.com/blog`, `site:medium.com/google-cloud`

### Web development (JS, không TS-only)
- `"Next.js release [year]"`, `"React compiler update [year]"`
- `"JavaScript ES2026"`, `"Node.js release [year]"`
- `"Vite vs Turbopack [year]"`, `"Bun update [year]"`
- `"Core Web Vitals best practice [year]"`, `"CSS container queries [year]"`
- `site:web.dev`, `site:developer.chrome.com`, `site:smashingmagazine.com`
- `site:blog.logrocket.com`, `site:vercel.com/blog`, `site:v8.dev`, `site:nodejs.org/blog`

### Shopify
- `Shopify changelog [current month year]`
- `site:shopify.dev/changelog [current month]`
- `Shopify Functions GraphQL API update [year]`
- `Shopify Checkout Extensibility news [year]`
- `Shopify Editions [season year]`

### AI / Security
- `"Claude Anthropic release this week"`, `"OpenAI announcement this week"`
- `CVE Shopify vulnerability [year]`, `"security breach [month year]"`

### Loyalty (chỉ khi có tin lớn)
- `Rivo loyalty launch major feature [year]`
- `BON Smile LoyaltyLion acquisition [year]`

### Tài chính Việt Nam (luôn search)
- `"giá vàng SJC hôm nay"`, `"giá vàng 9999 [day/month/year]"`
- `"VN-Index hôm nay"`, `"chứng khoán Việt Nam [day/month/year]"`
- `"bitcoin price today"`, `"ethereum price today"`
