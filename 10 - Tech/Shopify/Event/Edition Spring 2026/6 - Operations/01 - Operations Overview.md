# Operations Overview - Shopify Editions Spring '26

Section Operations trong Editions Spring '26 bao gồm **46 cập nhật** chia thành các nhóm chính: Analytics, Metafields, Orders/Returns, Shopify Flow, Admin UX, Inventory, Shipping, và Global/Managed Markets.

---

## Mục lục theo thứ tự đọc

1. [[02 - Analytics]] — data visualizations mới (scatter, radar, bubble, sunburst), daily insights, annotations, metric targets, multi-metric charts, filter theo metafields
2. [[03 - Metafields trong Admin]] — tạo metafield definitions in context, pin tối đa 50 metafields
3. [[04 - Orders, Returns & Draft Orders]] — discounts on refund page, consistent calculations, category-specific return reasons, custom pricing draft orders, order cancellation requests
4. [[05 - Shopify Flow]] — code editor, version history, workflow notes, automatic shipping label purchasing, ShopifyQL + Admin API fields
5. [[06 - Admin UX & Permissions]] — enhanced filtering/saved views, app activity visibility, staff payments permissions
6. [[07 - Inventory]] — SKU sharing, faster syncing, pickup fulfillment, barcode receiving, purchase order workflows, inventory adjustments
7. [[08 - Shipping]] — batch fulfillment, FedEx One Rate, advanced shipping options, carrier auto-detection, labels in local currency
8. [[09 - Global & Managed Markets]] — Managed Markets mở rộng UK/Canada, international pricing, duty breakdown, gift cards đa tiền tệ
