# Shopify Editions Spring 2026 — Overview

> Nguồn: https://www.shopify.com/editions/spring2026

Shopify Editions Spring '26 là đợt công bố sản phẩm nửa đầu năm 2026 của Shopify, với **150+ updates** trải khắp 10 mảng. Chủ đề trung tâm kỳ này: **Agentic Commerce** — đưa merchant hiện diện trên mọi AI channel (ChatGPT, Copilot, các AI agent cá nhân) thông qua Shopify Catalog, Universal Commerce Protocol và bộ MCP (Catalog / Cart / Checkout).

## Điểm đáng chú ý với app developer (Joy Loyalty context)

- **Sidekick works with apps**: app third-party (trong đó có Smile — đối thủ loyalty) tích hợp trực tiếp vào Sidekick → cần đánh giá cơ hội tích hợp tương tự
- **Shopify App Pricing**: cấu hình usage/recurring/hybrid pricing ngay lúc submit app
- **Stronger app security**: expiring tokens + OAuth 2.0 refresh flow
- **Built for Shopify requirement**: app returns/subscriptions bắt buộc dùng Customer Account API
- **Standard storefront events and actions**: chuẩn hoá cách app và AI agent tương tác với storefront
- **Discount configuration with admin UI extensions** + **prerequisites in product discount functions** + **bulk editing extensions for discounts**: nhiều thay đổi lớn về discount stack
