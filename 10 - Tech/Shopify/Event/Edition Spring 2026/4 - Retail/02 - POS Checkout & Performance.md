# POS Checkout & Performance

Nhóm feature cải thiện tốc độ và trải nghiệm checkout trên Shopify POS, release trong POS v11.0 (18/02/2026).

---

## Fastest-ever POS

POS mới được tối ưu hiệu suất toàn diện. Shopify cho biết merchant **tiết kiệm hơn 1 phút** khi thực hiện các thao tác tạo customer mới, thêm product, và checkout — nhờ giao diện cart luôn hiển thị (always-visible cart).

Đây không phải một feature riêng lẻ mà là kết quả tổng hợp của nhiều cải tiến performance xuyên suốt POS app.

**Availability:** Tất cả plan.

---

## Rebuilt POS Checkout

Checkout flow trong POS được rebuild lại hoàn toàn. Các cải tiến cụ thể (theo POS v11.0 changelog):

- **Always-visible cart:** Cart hiển thị xuyên suốt từ lúc chọn item đến khi payment — staff không bị mất context khi chuyển bước.
- **Faster payment tender selection:** Chọn phương thức thanh toán nhanh hơn.
- **Larger number pads:** Bàn phím số lớn hơn cho cash và split payments, hiển thị trong side panel.
- **Simplified split payment workflows:** Quy trình chia thanh toán được đơn giản hóa.
- **Clearer receipt selection:** Sau khi thanh toán xong, giao diện chọn receipt rõ ràng hơn.
- **Multi-select items:** Staff có thể chọn và chỉnh sửa nhiều item cùng lúc, giảm thao tác lặp trên order lớn.
- **Improved customer matching:** Autofill và matching thông minh hơn, hạn chế tạo duplicate customer.
- **Reorganized actions menu:** Các action được đặt gần nơi sử dụng thay vì ẩn trong menu.
- **Side panel workflows:** Customer attribution và staff attribution mở trong panel riêng thay vì popup.

**Availability:** Tất cả plan.

## Faster Search in POS

Cải thiện tốc độ tìm kiếm product, customer, và order trong POS. Hệ thống mới hiển thị inline suggestions và giảm latency đáng kể trên tất cả giao diện search.

**Availability:** Tất cả plan (yêu cầu POS v11.0+).

## Keyboard Shortcuts

Phím tắt giúp staff thao tác nhanh hơn khi dùng POS trên iPad hoặc desktop có bàn phím gắn ngoài.

### Cart & Menu Navigation

| Phím tắt | Hành động |
|---|---|
| `Escape` | Go back |
| `Cmd+F` | Search |
| `Cmd+O` | Search orders |
| `Cmd+Shift+H` | Go to Home |
| `Cmd+Shift+P` | Go to Products |
| `Cmd+Shift+O` | Go to Orders |
| `Cmd+Shift+C` | Go to Customers |
| `Cmd++` | Increase quantity |
| `Cmd+-` | Decrease quantity |
| `Cmd+[số]` | Select cart item |
| `Cmd+N` | Add/edit cart note |
| `Cmd+Enter` | Start checkout |
| `Cmd+K` | Display shortcuts |
| `Cmd+0` | Remove cart item |
| `Cmd+U` | Add customer |

### Segment Control Tabs

| Phím tắt | Hành động |
|---|---|
| `Cmd+Shift+]` | Next tab |
| `Cmd+Shift+[` | Previous tab |

### List & Dialog Navigation

| Phím tắt | Hành động |
|---|---|
| `Arrow Down / Up` | Highlight next/previous item |
| `Enter` | Select highlighted item |
| `Escape` | Close dialog |

**Availability:** Tất cả plan.

## Editor Works with Smart Grid

Giao diện POS editor cho phép merchant tùy chỉnh smart grid từ Shopify Admin:

- **Template management:** Tạo và quản lý nhiều smart grid layout bằng template. Một template mặc định áp dụng cho tất cả POS location mới.
- **Tile customization:** Add, edit, rearrange, recolor, hoặc remove tiles trên từng tile page.
- **Tile pages:** Add, rearrange, hoặc remove tile pages.
- **Preview modes:** Chuyển đổi giữa tablet/smartphone view và dark/light mode.
- **Lock screen:** Tùy chỉnh lock screen của POS.

### Permissions cần thiết

- **Admin:** Products > View và Store settings > Locations permissions.
- **Discount tiles:** Cần thêm Discounts permission.
- **On-device editing:** Staff cần permission "Customize smart grid".

**Availability:** Tất cả plan.
