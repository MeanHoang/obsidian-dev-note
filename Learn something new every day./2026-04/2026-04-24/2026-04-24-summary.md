## 🔥 Firebase & GCP
- ⭐ **[What's new from Firebase at Cloud Next 2026](https://firebase.blog/posts/2026/04/cloud-next-2026-announcements)** (22/04/2026)
  **Đây là gì:** Bài tổng hợp chính chủ Firebase sau Google Cloud Next '26. Highlights: **Firebase SQL Connect** (evolved từ Data Connect, hỗ trợ viết query bằng SQL thay vì GraphQL, realtime sync + offline cache trên Cloud SQL Postgres); **Firestore Enterprise GA** với full-text search + geospatial query native; **Application Design Center** integration để deploy gộp Firestore/App Check/Auth/AI Logic; **Dart support** cho Cloud Functions; **Firebase Phone Number Verification** GA vào tháng 5/2026.
  **Vì sao đáng đọc:** Joy stack Firebase-first. SQL Connect có thể thay thế nhiều custom query logic hiện dùng Firestore thuần. Full-text search native xoá nhu cầu sync qua Algolia/Typesense.
- **[cloud-run-mcp — GitHub](https://github.com/GoogleCloudPlatform/cloud-run-mcp)**
  **Đây là gì:** **MCP (Model Context Protocol)** là chuẩn mở Anthropic đưa ra để AI agent gọi tool/service. `cloud-run-mcp` là MCP server chính thức của Google để AI agent (Claude Code, Gemini CLI) deploy source code → Cloud Run qua prompt. Repo update tuần này, GA tại Next '26.
  **Vì sao đáng đọc:** Cài MCP này vào Claude Code, deploy Joy backend service (Functions v2 / Cloud Run) không cần nhớ gcloud flags. Giảm friction rollout.
- **[Firestore release notes](https://docs.cloud.google.com/firestore/docs/release-notes)**
  **Đây là gì:** Trang release notes chính thức. Tuần này xác nhận nhiều GA: text search, geospatial, database clone, regional endpoints. Pipeline Operations (query engine mới với 100+ operator kiểu SQL) đã stable.
  **Vì sao đáng đọc:** Bookmark để check định kỳ — đây là nguồn duy nhất chính xác về feature flag / GA status cho database chính của Joy.

## 🛒 Shopify Platform & API
- ⭐ **[Storefront filter URLs now use stable identifiers instead of text values](https://changelog.shopify.com/posts/storefront-filter-urls-now-use-stable-identifiers-instead-of-text-values)** (deadline 24/04)
  **Đây là gì:** URL filter storefront (kiểu `?filter.v.option.color=Blue`) chuyển sang dùng **stable GID** (`?filter.v.option.color=gid://shopify/FilterSettingGroup/123`). Lý do: label text đổi theo ngôn ngữ và có thể rename; GID ổn định qua mọi thay đổi đó. Format mới đã rollout từ **16/03/2026**; link cũ tạo trước ngày đó **ngừng apply filter từ 24/04/2026** (hôm nay).
  **Vì sao đáng đọc:** Joy nếu có feature generate deep link filter cho merchant (campaign email, social share có pre-applied filter) cần regen. Fix trước khi merchant báo "link cũ không còn filter nữa".
