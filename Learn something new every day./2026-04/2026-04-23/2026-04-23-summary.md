## 🏗️ System Design / Architecture

- ⭐ **[Shopify's journey to faster breadth-first GraphQL execution](https://shopify.engineering/faster-breadth-first-graphql-execution)** (Shopify Engineering, 12/03/2026 — note muộn vì đáng đọc)
  **Đây là gì:** GraphQL theo chuẩn execute depth-first (mỗi field resolve theo cây). Shopify build engine breadth-first: resolve mỗi field 1 lần across tất cả objects cùng level, gom batch lookup. Open letter cho cộng đồng GraphQL.
  **Vì sao đáng đọc:** Joy gọi Shopify GraphQL Admin nhiều, hiểu cost model bên trong giúp optimize query (gộp field trùng level, tránh nested cardinality lớn). Pattern dùng được trong tự build GraphQL gateway nội bộ.

- **[2,000 robots walk into a shop: Simulated A/B testing — SimGym](https://shopify.engineering/simgym)** (Shopify Engineering, 27/02/2026)
  **Đây là gì:** Hệ thống "SimGym" của Shopify cho phép 2,000 AI agent (mỗi con có persona + intent shopping) duyệt storefront trong cloud browser, chạy synthetic A/B test trong vài phút thay vì cần real traffic. Tận dụng NVIDIA Blackwell tối ưu inference.
  **Vì sao đáng đọc:** Pattern dùng AI agent thay traffic thật để test feature/UX. App Joy có thể adopt nguyên lý này để test pre-launch widget loyalty trước khi merchant production.

## 🌐 Web Development

- ⭐ **[Partial Prerendering (PPR) in Production: Architecture Patterns 2026](https://samcheek.com/blog/nextjs-partial-prerendering-production-2026)**
  **Đây là gì:** PPR là kỹ thuật rendering Next.js — decompose page tại Suspense boundary, CDN serve static shell + stream dynamic content tại request time. Build-time tạo shell, request-time chèn personalized content. Stable từ Next.js 15.
  **Vì sao đáng đọc:** Pattern thay thế cho mô hình "all SSR hoặc all SSG": product page có shell static + giỏ hàng dynamic, TTFB <50ms. Áp dụng cho Joy storefront extension nếu có Next.js side. Cảnh báo: phải design fallback skeleton chính xác để tránh CLS.

## 🔒 Security

- **[CVE-2026-39320 — SignalK Server ReDoS via WebSocket subscription (CVSS 7.5)](https://advisories.gitlab.com/npm/signalk-server/CVE-2026-39320/)**
  **Đây là gì:** ReDoS = Regular Expression Denial of Service. Inject regex metacharacter vào tham số `context` của WebSocket subscription → catastrophic backtracking, CPU 100%, server treo. Không cần auth. Affected: tất cả version <2.25.0.
  **Vì sao đáng đọc:** Joy có thể không dùng SignalK trực tiếp, nhưng pattern ReDoS phổ biến — kiểm tra bất kỳ code nào nhận input user rồi pass vào regex/RegExp.test() (đặc biệt Cloud Functions trigger).
