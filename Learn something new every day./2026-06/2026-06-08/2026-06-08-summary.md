> [!warning] 📌 Note thêm — Shopify Scripts → Functions (deadline 30/6/2026)
> **Mốc thời gian cần nhớ:**
> - **15/4/2026** — hạn migrate *khuyến nghị* (Shopify recommend xong trước mốc này để có buffer test).
> - **30/6/2026** — Scripts **ngừng thực thi hẳn**. Sau ngày này mọi Ruby Script ở checkout không còn chạy → ưu đãi/điểm dựa trên Script sẽ âm thầm fail.
>
> **Khác biệt cốt lõi Scripts vs Functions:**
> - Scripts = Ruby chạy trên server Shopify, chỉ Shopify Plus, edit trực tiếp trong Script Editor.
> - Functions = code **JS hoặc Rust → compile sang WASM**, deploy kèm app (qua Shopify CLI), chạy được cho cả non-Plus tuỳ API. Logic là **pure function**: input = JSON (cart/context) → output = list operations (discount/shipping/payment), **không gọi network/DB ngoài** trong lúc chạy.
> - Hệ quả với Joy: data cần để tính ưu đãi (vd tier/điểm member) phải được **nạp sẵn vào input** qua metafields/cart attributes, **không** fetch Firestore trong Function. Cần thiết kế lại luồng: app sync state → metafield → Function đọc metafield.
>
> **Action items cho Joy Loyalty:**
> - [ ] Audit codebase tìm mọi chỗ còn dùng Shopify Scripts (discount điểm, ưu đãi tier, free shipping reward...).
> - [ ] Map từng Script → loại Function tương ứng: **Discount Function** (giảm giá theo điểm/tier), **Shipping Function** (free ship reward), **Payment Function** (ẩn/hiện phương thức).
> - [ ] Xác định data dependency của mỗi rule → đẩy vào **metafield/cart attribute** thay vì query runtime.
> - [ ] Tận dụng Admin API 2026-04: hỗ trợ **nhiều product discount trên 1 cart line** → combo reward + voucher dễ hơn khi port.
> - [ ] Test trên dev store trước 15/4, theo dõi [shopify.dev/changelog](https://shopify.dev/changelog) cho cập nhật cuối.
