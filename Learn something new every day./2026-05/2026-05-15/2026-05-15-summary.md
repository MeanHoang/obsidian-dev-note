## 🛒 Shopify Platform & API
- ⭐ **[Storefront API 2026-07 — Cart warnings cho delivery option](https://shopify.dev/changelog/the-storefront-apis-cart-object-now-exposes-warnings-for-unavailable-delivery-options)** (shopify.dev changelog)
  **Đây là gì:** Storefront API 2026-07 (version mới) thêm warning vào `Cart` object khi delivery option buyer đã chọn không còn available (vd: shipping rate đổi, location đổi). Mỗi warning có target trỏ về cart line cụ thể.
  **Vì sao đáng đọc:** Headless storefront merchant Joy cần code defensive cho reward shipping (free shipping reward, discounted rate) — giờ có warning chuẩn để render UI thay vì để buyer ngạc nhiên ở step thanh toán.
- **[PRODUCT_UNAVAILABLE_IN_BUYER_LOCATION warning code](https://shopify.dev/changelog/new-productunavailableinbuyerlocation-warning-code-in-the-storefront-api-cart)** (shopify.dev changelog)
  **Đây là gì:** Bổ sung warning code chuyên cho trường hợp sản phẩm không bán ở location của buyer (geo-restricted, market-specific). Warning trả về kèm CartLineID để map UI.
  **Vì sao đáng đọc:** Merchant Joy bán đa quốc gia (Markets) cần handle case này khi reward unlock một sản phẩm mà buyer không mua được — UX kém nếu silent ignore.
- **[Shopify Functions run logs include production store executions](https://shopify.dev/changelog/shopify-functions-run-logs-now-include-production-store-executions)** (shopify.dev changelog)
  **Đây là gì:** Dev Dashboard logs giờ hiển thị cả lần chạy Function trên production store của merchant (không chỉ dev store như trước). Filter theo scope của app.
  **Vì sao đáng đọc:** Joy có loyalty discount Function — bug khó nhất là "production khác dev" do dữ liệu thật. Có log production = debug được mà không cần merchant share quyền truy cập store.
