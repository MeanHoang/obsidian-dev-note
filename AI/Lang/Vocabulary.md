# 📝 Vocabulary — Từ tiếng Anh hay gặp

> Những từ tiếng Anh thường gặp khi đọc docs, blog, tutorial về AI/LLM. Không phải thuật ngữ kỹ thuật — chỉ là từ vựng giúp đọc hiểu nhanh hơn.

---

| Từ              | Nghĩa                    | Ví dụ context                                                                                                                            |
| --------------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **overwhelm**   | quá tải, ngợp            | "Too much data overwhelms the LLM" — nhét quá nhiều data → LLM không xử lý nổi                                                           |
| **pitfalls**    | bẫy, lỗi hay mắc         | "Common pitfalls" — những lỗi thường gặp nên tránh                                                                                       |
| **boilerplate** | code mẫu lặp lại         | "Reduce boilerplate" — giảm code rập khuôn                                                                                               |
| **leverage**    | tận dụng                 | "Leverage LLM for automation" — tận dụng LLM để tự động hóa                                                                              |
| **verbose**     | dài dòng                 | "Too verbose output" — output quá nhiều chữ, lan man                                                                                     |
| **deprecated**  | lỗi thời, không dùng nữa | "This method is deprecated" — method này sắp bị xóa, dùng cái mới đi                                                                     |
| **caveats**     | lưu ý, điều cần cẩn thận | "Caveats when using RAG" — những điều cần chú ý khi dùng RAG                                                                             |
| **robust**      | chắc chắn, đáng tin cậy  | "Robust error handling" — xử lý lỗi kỹ càng, không dễ crash                                                                              |
| **sensitive**   | nhạy cảm                 | "Sensitive data" — dữ liệu nhạy cảm (password, API key). "Sensitive actions" — hành động cần confirm trước khi làm (xóa data, gửi email) |
| **retrieval**   | truy xuất, tìm lại       | "Retrieval from vector database" — tìm và lấy lại dữ liệu liên quan từ database                                                          |
| **sparse**      | thưa, rải rác            | "Sparse search uses keyword matching" — tìm kiếm dựa trên từ khóa, ngược với dense (dày đặc, theo ngữ nghĩa)                             |
| **dense**       | dày đặc, đầy đủ          | "Dense search uses vector similarity" — tìm kiếm theo ngữ nghĩa dùng vector, ngược với sparse (thưa, theo từ khóa)                       |
| **citation**    | trích dẫn nguồn          | "Include citations in RAG responses" — cho user biết câu trả lời lấy từ tài liệu nào, trang nào                                          |
| **utility**     | tiện ích, công cụ phụ trợ | "3 key utility classes in LCEL" — những class hỗ trợ giúp ghép nối component dễ hơn                                                       |
| **alternatives** | lựa chọn thay thế       | "Lighter alternatives to LangChain" — các tool/framework khác có thể dùng thay LangChain                                                  |
| **fork**         | rẽ nhánh, tách ra        | "Fork execution into parallel branches" — tách luồng xử lý thành nhiều nhánh chạy cùng lúc                                               |
