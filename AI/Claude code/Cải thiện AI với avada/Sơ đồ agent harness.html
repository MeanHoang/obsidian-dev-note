Sơ đồ agent harness Joy

Nguồn: Sổ tay harness.md + .claude/roles/*.md + .claude/workflow/blocks/K0–K7 (bản 29/09/2026, đã bỏ tracer, decider).

  1. Hình sao: anh chỉ nói chuyện với parent. Parent giao việc cho từng sub agent, và sub agent chỉ trả kết quả về parent.
  2. Sub agent không nói chuyện ngang với nhau. Role nào cần việc của role khác thì trả về parent, để parent giao tiếp.
  3. Mỗi lần giao việc, parent dán file role (roles/<role>.md) và khối sẽ chạy (blocks/K*.md) vào prompt.
  4. Bộ nhớ chung của task nằm ở .claude/ship/<task>/. Parent giữ progress.md và decisions.md.
  5. 🚦 = parent dừng, báo anh, rồi kết thúc lượt. Im lặng không được tính là đồng ý.

2. Ba luồng: role nào chạy lúc nào

  1. parent
    Mở việc K0: worktree từ origin/master, kiểm tra auth, tạo .claude/ship/<task>/
  2. scout ×1×3 song song nếu bug khó
    3 chân bằng chứng K1: vấn đề · code trên master · setting thật (MCP Joy → Chrome admin → Chrome storefront). Parent tự mở lại file:line quan trọng.
  3. verifier
    Tái hiện K2: FE thì chụp ảnh bug, BE thì viết test/script FAIL
  4. parent
    Verdict fix / skip / need-data / need-logging + số shop bị ảnh hưởng 🚦 dừng
  5. verifier
    FE: sửa thử live trên trình duyệt K3 bước 1 → 2 ảnh 🚦 anh duyệt
  6. implementer
    Code K3, phải ghi rõ đã bê pattern từ file:line nào
  7. verifier
    Xác nhận K4: ảnh sau / test PASS (output thô)
  8. reviewer
    Review 1 vòng K5: 1 sub agent chạy /review → parent tự verify lại từng finding
  9. parent
    Commit K6, chỉ file của task 🚦 chờ chữ "commit"
  10. parentverifier
    Ship K7: push, MR, deploy, test lại staging, chỉ khi anh bảo 🚦

4. Bộ tiêu chuẩn của role lớn dần thế nào

  1. anh
    Sửa lưng một agent, ví dụ "sao lại đặt tên chung chung thế".
  2. parent
    Soạn 1 dòng tiêu chuẩn + role áp dụng, rồi hỏi: "Thêm vào Standards của implementer: '…'?" Không tự ghi, vì có hook memory-consent.
  3. anh
    Gật → dòng đó được ghi vào mục ## Standards của roles/<role>.md, kèm ngày + câu gốc của anh.
  4. parent
    Lần giao việc sau, file role được dán vào prompt, nên sub agent đọc tiêu chuẩn ngay từ đầu.
  5. parent
    Dòng nào bị vi phạm lần 2 → chuyển xuống hook hoặc test (chặn cứng).
