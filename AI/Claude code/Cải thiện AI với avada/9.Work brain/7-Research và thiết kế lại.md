## Nguồn 2 — Mẫu LLM Wiki của Karpathy (04/2026)
Nguồn: https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f

- 3 lớp: `raw/` (tài liệu gốc, không sửa) → `wiki/` (agent viết và giữ) → `CLAUDE.md` (luật của wiki).
- 3 việc: **ingest** (nạp tài liệu thành trang wiki), **query** (hỏi đáp dựa trên wiki), **lint** (dọn: trùng, mâu thuẫn, link gãy).
- Câu chính: "stop re-deriving, start compiling". Nghĩa là viết lại kiến thức một lần cho gọn, đừng để agent lục lại tài liệu gốc mỗi lần.

**Skill đã cài sẵn trên máy làm đúng mẫu này:** plugin `claude-obsidian` (bản 1.9.2)
- `/wiki` dựng khung vault: `.raw/`, `wiki/index.md`, `wiki/log.md`, `wiki/hot.md`, git.
- `wiki-ingest`: nạp file vào wiki → **dùng để chuyển bộ nhớ cũ sang**, không phải tự chép tay.
- `wiki-lint`: kiểm trang mồ côi, link chết, nội dung cũ, mâu thuẫn.
- `save`: lưu câu trả lời hay vào wiki.
- `hot.md`: tóm tắt khoảng 500 chữ về "đang làm gì", cập nhật cuối mỗi phiên → thay cho `work/now.md` em đề xuất trước đó.
- Cách cho project khác đọc: thêm vào `CLAUDE.md` "đọc `hot.md` trước → `index.md` → chỉ mở trang cần".

Giới hạn cần biết của plugin:
1. Hook của plugin chỉ đọc `wiki/hot.md` khi Claude **mở ngay trong thư mục vault**. Mở ở `joy` thì không tự đọc → vẫn cần `~/.claude/CLAUDE.md` trỏ tới.
2. Plugin có lỗi hook không in ra được (`anthropics/claude-code#10875`) → phải thử thật.
3. Plugin làm cho **kiến thức** (tài liệu, nghiên cứu). Không làm cho **luật hành xử** của agent. Luật vẫn đặt ở `~/.claude/rules/`.

## Thiết kế lại: 3 tầng, mỗi tầng dùng đúng công cụ có sẵn

Ví von: **luật** = nội quy công ty dán ở cửa, ai vào cũng đọc. **Wiki** = thư viện, cần thì mới vào tra. **Auto-memory** = giấy nhớ dán tạm, cuối tuần mới chép vào sổ.

| Tầng | Chứa gì | Đặt ở đâu | Ai ghi | Nạp khi nào |
|---|---|---|---|---|
| 1. Luật | Anh là ai, cách làm việc, code style | `~/work-brain/rules/*.md`, link sang `~/.claude/rules/` | Anh (agent đề xuất) | Mọi phiên, mọi thư mục |
| 2. Wiki | Kiến thức Joy, môi trường, hệ thống, task đã xong | `~/work-brain/wiki/` (khung của `/wiki`) | Agent qua `wiki-ingest`, `save` | Đọc `hot.md` → `index.md` → trang cần |
| 3. Giấy nhớ | Bài học mới chưa duyệt | **Giai đoạn 1: để nguyên** `~/.claude/projects/<repo>/memory/` (xem mục "Rủi ro" bên dưới) | Auto-memory, chỉ khi anh bảo (hook `memory-consent`) | 200 dòng đầu `MEMORY.md` |

Cây thư mục:
```
~/work-brain/                 # git repo, can also be opened as its own Obsidian vault
├── CLAUDE.md                 # wiki rules (generated by /wiki)
├── rules/                    # layer 1: always loaded, < 200 lines total
│   ├── me.md                 # who I am: role, company, stack
│   ├── how-i-work.md         # ask when unclear, no commit without "commit", verify before "fixed"
│   └── code-style.md         # null not undefined, reuse before create, no forced DRY
├── wiki/                     # layer 2: read on demand
│   ├── hot.md                # what I'm working on now (~500 words)
│   ├── index.md              # one line per page, agent picks pages from here
│   ├── log.md                # append-only change log
│   └── domains/joy/ …        # Joy knowledge: environments, dev pitfalls, field whitelists
└── .raw/                     # copies of old memory files, input for wiki-ingest
```

`~/.claude/CLAUDE.md` (khoảng 10 dòng):
```markdown
@~/work-brain/wiki/hot.md
Work knowledge: read ~/work-brain/wiki/index.md, open only pages the task needs.
```
`~/.claude/rules/` → symlink tới `~/work-brain/rules/` (cần thử; nếu không nạp thì dùng `@import` trong `~/.claude/CLAUDE.md`).

## Rủi ro phát hiện khi đọc lại (2026-10-01)
Ba lý do **chưa nên** dùng `autoMemoryDirectory` ở giai đoạn 1:
1. **Hook `memory-consent` mất tác dụng.** Hook này (`joy/.claude/hooks/memory-consent.sh`) chặn agent ghi memory khi anh chưa bảo. Nó chỉ canh đường dẫn `*/.claude/projects/*/memory/*`. Đổi chỗ ghi sang `~/work-brain/memory/` thì agent ghi tự do. Muốn đổi phải sửa hook trước.

3. **Đặt ở cấp user thì kéo cả note học vào.** `autoMemoryDirectory` trong `~/.claude/settings.json` áp cho mọi thư mục, kể cả vault Obsidian (16 file quy tắc viết note Java). Ngược với mục tiêu "chỉ công việc". Nếu dùng thì đặt riêng trong settings của từng repo Joy.
